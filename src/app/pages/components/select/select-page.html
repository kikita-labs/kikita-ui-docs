• The trigger input uses combobox semantics and reflects dropdown expanded state.
  • Dropdown panel uses listbox semantics; each kuiOption is an option.
  • Use kui-field for label, hint, error, and described-by wiring.
  • Each kuiOption exposes aria-selected and aria-disabled.
  • The clear affordance is a native button named Clear, and the options toggle is named by the kuiSelect.openOptions and kuiSelect.closeOptions messages.
  • Enter or Space opens the dropdown and then selects the focused option; ArrowDown and ArrowUp open it and focus the first or last option; Escape closes it; Tab closes it through the focused option flow.
  • Multiple selected values render removable chip buttons named by the kuiSelect.removeItem message. maxVisibleChips is count-based and does not measure the field width.
  • touch is emitted after an opened dropdown closes, which marks the control touched for Signal Forms.
  • The classes are KuiSelect, KuiSelectValue, KuiOption and KuiDropdown; the Directive and Component suffixes are gone.
  • kuiProvideSelectOptions and KUI_SELECT_OPTIONS are replaced by provideKuiDefaults({{ '{' }} select: {{ '{' }} ... {{ '}' }} {{ '}' }}); clearable resolves as local input, then defaults.select, then defaults.field, then false.
  • The legacy tokens --kui-select-bg, --kui-select-border, --kui-select-border-hover, --kui-select-border-focus, --kui-select-border-error and --kui-select-radius were removed; use the shared --kui-input-* tokens.
  • chevronIcon and clearIcon defaults set the glyphs of the options toggle and the clear button.
  • The open, close and chip remove button names come from the kuiSelect messages.
