• Segmented now implements FormValueControl<string> and accepts [formField] directly on kui-segmented for Signal Forms integration.
  • The selected/selectedChange model is deprecated in favor of value/valueChange. Existing [(selected)] bindings keep working and stay in sync with value, but are planned for removal in the next major version. New markup should use [(value)].
  • The container renders role="radiogroup".
  • ArrowLeft, ArrowRight, ArrowUp and ArrowDown move focus between segments; Home and End focus the first and last; Enter and Space select the focused segment.
  • Each segment button renders role="radio" and selection state.
  • Disabled segments cannot be selected.
  • focus() lands on the selected segment, so Signal Forms focusBoundControl() reaches the control instead of the group host.
  • Use an accessible label on the segmented group when nearby text is not enough.
  • The classes are KuiSegmented and KuiSegment; the Component and Directive suffixes are gone.
  • The default size moved to provideKuiDefaults({{ '{' }} segmented: {{ '{' }} size {{ '}' }} {{ '}' }}); the input is now undefined until set.
  • kui-segmented gains focus(options?), so Signal Forms focusBoundControl() reaches the selected segment.
  • ArrowUp and ArrowDown now also move focus between segments.
  • The focus ring has --kui-seg-focus-ring-color, and disabled segments use the shared --kui-opacity-disabled.
