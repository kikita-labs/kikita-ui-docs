• Checkable mode cascades checked state to non-disabled descendants.
  • Partially checked parents expose mixed state when descendants differ.
  • Lazy nodes call loadChildren once on first expansion and cache the result.
  • Built-in icons are limited to folder and file; very large trees are not virtualized.
  • Set ariaLabel when nearby text does not already name the tree.
  • Arrow keys, Home, End, Enter, Space, and type-ahead move through visible nodes.
  • Disabled nodes stay reachable by navigation but cannot be selected or checked.
  • The root is role="tree" and nodes are role="treeitem" with aria-expanded, aria-selected (display) or aria-checked (checkable, including mixed), and aria-level, aria-setsize and aria-posinset. Exactly one node is in the tab order (roving tabindex).
  • Without ariaLabel the tree is named by the tree.label message.
  • Use mobile mode where touch targets need the larger 44px toggle affordance.
  • The component class is KuiTree; the Component suffix is gone.
  • Size and mode defaults moved to provideKuiDefaults({{ '{' }} tree: {{ '{' }} size, mode {{ '}' }} {{ '}' }}), together with the disclosureIcon glyph; the inputs are now undefined until set.
  • The default ariaLabel comes from the tree.label message.
  • Row, spinner and focus colours have tokens, plus gap, padding, font-size and icon-size geometry tokens.
