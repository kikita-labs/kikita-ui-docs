• Pane sizes are percentages of the splitter's own container, computed with calc() against the fixed gutter width, so panes and gutters always add up to 100%.
  • minSize (default 10) is a percentage floor that stops an accidental drag or keyboard step from collapsing a pane to nothing.
  • A collapsible first or last pane gets a one-touch button on its gutter that toggles it between its minSize and its size before collapsing; Enter on the gutter does the same. A middle pane's flag is ignored.
  • The gutter renders an inner role="separator", focusable unless disabled. The kui-splitter-gutter host has no role, and the collapse button is a sibling of the separator because a focusable separator must not contain an interactive control.
  • aria-orientation describes the gutter line: horizontal panes have a vertical line, and vice versa.
  • aria-valuenow, aria-valuemin and aria-valuemax track the pane before the gutter from the same value that drives the visual size, and aria-controls points at that pane's generated id, which replaces any id set in a template.
  • The collapse button is named by the splitter.collapsePane and splitter.expandPane messages and stays out of the tab order; its keyboard equivalent is Enter on the separator.
  • Tab focuses each gutter. The arrow keys along the layout axis resize the before pane by 2%, or 10% with Shift. Home collapses it to its minSize and End expands it to the maximum the after pane allows. Escape cancels an active drag and restores the earlier sizes.
  • There is no custom thumb projection; only the default grip and the chevron button exist.
  • Sizes are not persisted between sessions.
  • The gutter strip is 8px, below the 44px touch-target guidance, as a desktop cursor-driven control.
  • A formal assistive-technology review has not been run.
