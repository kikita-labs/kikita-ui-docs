Signal Forms supplies raw validity through the native control invalid property. The Field gates the displayed state on touch, so with [formField] the input follows the Field state instead of treating a raw invalid binding as a manual override.

  • Keep the native input semantics; do not add an ARIA role.
  • Give every input an accessible name through a kui-field label, a native label or aria-label. A placeholder alone is not a label.
  • Inside a Field the input uses the generated control id and references only the rendered hint and error through aria-describedby; a visible error is role="alert".
  • aria-invalid is omitted while valid; when invalid the directive sets aria-invalid="true" and data-kui-invalid.
  • Keep disabled and readonly distinct: a read-only input stays focusable. Required semantics come from native HTML or Signal Forms, not the Field marker.
  • Decorative affix icons use aria-hidden="true".
  • Interactive field actions must be native buttons with accessible names.
  • kuiInput adds no keyboard handlers: Tab focus, editing and type-specific keys stay native.
  • The directive class is KuiInput; the Directive suffix is gone.
  • The default size moved to provideKuiDefaults({{ '{' }} input: {{ '{' }} size {{ '}' }} {{ '}' }}); the old provideKikitaUi({{ '{' }} input {{ '}' }}) shape is deprecated.
  • Input height and font size per size now have geometry tokens (--kui-input-height-*, --kui-input-font-size-*).
  • A Field size only styles descendant inputs without data-kui-size, so an input with an explicit size keeps it inside a differently sized Field.
  • With [formField], kuiInput follows the Field's touch-gated invalid state.
