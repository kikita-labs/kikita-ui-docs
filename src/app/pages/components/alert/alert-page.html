• appearance="danger" renders role="alert" with aria-live="assertive"; every other appearance uses role="status" with aria-live="polite". Both are aria-atomic="true".
  • The alert itself is not in the tab order; only its action and close buttons are.
  • The close button has an accessible name from closeLabel or the alert.close message.
  • Severity is never colour-only: info, success, warning and danger pair an icon with text. neutral has no icon because it carries no severity.
  • Escape does not close an alert.
  • The close button hit target is 28px (kuiIconButton size="xs"), below the 44px platform recommendation. The toast shares this limitation.
  • A formal assistive-technology review of the alert has not been run yet; see state-coverage.md in the library repository.
