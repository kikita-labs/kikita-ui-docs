• Use a non-interactive host such as span for a static chip.
  • Use a native button or a for an interactive chip.
  • Prefer removable with a value-specific removeLabel, for example removeLabel="Remove Design". Use a projected button[kuiChipRemove] with its own accessible name only when the default button isn't enough; do not combine both on the same chip.
  • Disabled chips mark the remove button aria-disabled="true" and tabindex="-1".
  • Select and Combobox own keyboard behavior for Delete/Backspace selected-value removal; do not duplicate that handling when Chip is used inside those controls.
  • The classes are KuiChip and KuiChipRemove (they had a Directive suffix); ng update @kikita-labs/ui renames the imports. kuiIconButton inside a chip is now KuiIconButton.
  • The size falls back to defaults.chip.size, and the remove icon to defaults.chip.removeIcon (then defaults.icons.remove). The remove mark is drawn by the shared structural icon renderer.
  • The disabled state dims to the shared 0.5 opacity (it was 0.4), the focus ring is a 2px outline, and a pressed chip keeps system colours in forced colors mode.
