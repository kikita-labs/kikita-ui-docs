For custom checkbox-like components prefer the Angular Signal Forms FormCheckboxControl contract over a ControlValueAccessor.

  • Use a native label for the checkbox option text.
  • Use kui-field for group label, hint, error, and described-by wiring.
  • Use native checked and disabled states; do not replace the input with a custom role.
  • Use invalid only when the checkbox is outside a field error state.
  • Inside kui-field the control receives the field id and aria-describedby, and an explicit required on the field or a Signal Forms required(...) validator is exposed as aria-required.
  • Focus is a solid 2px outline in --kui-color-focus. Disabled checkboxes dim to the shared 0.5 opacity, and checked and indeterminate states keep system colours in forced colors mode.
  • .kui-checkbox styles the native :indeterminate pseudo-class (a dash mark instead of a checkmark). indeterminate is a DOM property, not an HTML attribute, so set it imperatively on the element.
  • The class is KuiCheckbox (it was KuiCheckboxDirective); the selector and inputs are unchanged. ng update @kikita-labs/ui renames the import.
  • The size comes from the parent field, then defaults.checkbox.size, then the global defaults.size.
  • The control reads its host id, invalid state and aria-describedby from one internal helper and, inside kui-field, no longer pulls the whole field into your bundle.
  • The focus ring is a 2px outline, disabled controls dim to the shared 0.5 opacity, and checked and indeterminate states have forced-colors styling.
