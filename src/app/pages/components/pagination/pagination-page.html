currentPage and pageSize are plain two-way bindings, not form values: pagination is page-level navigation state and is never placed inside kui-field.

Changing the rows-per-page picker sets pageSize and resets currentPage to 1 in the same update, since a stale page offset into a resized list would be wrong.

  • The controls sit in a nav landmark named by ariaLabel or the pagination.label message, separate from the primary navigation.
  • The current page has aria-current="page" and the name Page N, current.
  • First, Prev, Next and Last are icon buttons with a required aria-label; at the range boundary they get the native disabled attribute and leave the tab order.
  • The ellipsis is aria-hidden and not focusable.
  • The full-variant summary is aria-live="polite".
  • There is no roving tabindex or arrow-key navigation: Tab and Shift+Tab move between the non-disabled controls in visual order, and Enter or Space activates the focused one.
  • There is no jump-to-page input; add a Number Input next to the group if a product needs it.
  • The ellipsis is static and has no hover-to-jump affordance.
  • The rows-per-page select sits in a label-less field with an aria-label on the input, so the open listbox panel carries no separate name.
  • A formal assistive-technology review has not been run.
