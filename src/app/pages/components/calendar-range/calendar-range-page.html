viewDate defaults to the current month; the documented fallback to the month of value.start applies only when the value exists at construction, so bind [(viewDate)] to open the grid at the month of a template-bound range. end is null while the range is still open, so check it before using the value as a closed range. The header navigation and the Today button are ghost kuiButtons and the rule above the footer is hr[kuiSeparator]. Calendar Range reuses the Calendar stylesheet and class names, so it shares the Calendar theming tokens listed below.

  • The day grid is a complete ARIA grid: role="grid", a weekday header row of columnheader cells and six week rows of seven gridcells, each wrapping one day button.
  • aria-selected sits on the gridcells of the range endpoints and any single committed day; today exposes aria-current="date" and disabled dates aria-disabled.
  • One day cell is in the tab order at a time; the arrow keys, Home, End, PageUp and PageDown move focus without leaving the grid.
  • Keyboard: ArrowLeft and ArrowRight move a day, ArrowUp and ArrowDown a week, Home and End the start and end of the week, PageUp and PageDown a month (with Shift a year), and Enter or Space selects the focused date.
  • Month and year changes are announced through an aria-live="polite" region.
  • There is no built-in popover wrapper (a range equivalent of input[kuiDatePicker]); the component is inline-only.
  • Selecting more than one start and end pair is not implemented.
