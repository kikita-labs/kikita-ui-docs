Project kui-icon directly when the icon needs source or src instead of a registered name.

Resolution order, highest priority first:

  • the local input;
  • defaults.button (or defaults.iconButton);
  • the global defaults.size, for the size only;
  • the component default.

kuiButton and kuiIconButton are configured through separate button and iconButton keys, so one never restyles the other. A nested provider merges with its parent per property.

  • Use <button> for in-page commands and form actions.
  • Use <a> only for real navigation with an href.
  • Every button needs an accessible name. Prefer visible text labels; icon-only actions should use kuiIconButton with an aria-label.
  • Native keyboard behavior is preserved: Enter and Space activate a button, links use native anchor behavior. The directive adds no custom keyboard model.
  • A disabled button uses the native disabled attribute. A disabled anchor gets aria-disabled="true", is removed from the tab order and suppresses navigation.
  • loading keeps the button's original content in layout, centers a spinner over it, sets aria-busy="true", and behaves like disabled until it clears.
  • Focus is a solid 2px outline in --kui-color-focus; no ring depends on box-shadow.
  • The class is KuiButton (it was KuiButtonDirective); the selector, inputs and class names are unchanged. ng update @kikita-labs/ui renames the import.
  • Defaults moved to provideKuiDefaults and defaults.button. The KUI_BUTTON_OPTIONS token is removed and kuiProvideButtonOptions is deprecated until 3.0. A nested provider now merges with its parent per property.
  • KuiButtonOptions describes one button. The old shape with button and iconButton keys is KuiButtonProviderOptions (deprecated).
  • The compatibility tokens --kui-btn-bg, --kui-btn-color and their siblings are no longer generated. Override the canonical --kui-btn-solid-* and --kui-btn-soft-* tokens, or the per-appearance tokens above.
  • Disabled buttons dim to the shared --kui-opacity-disabled (0.5), and a loading button no longer dims.
