• Use a visible label through kui-field or a native label; otherwise provide aria-label.
  • Arrow keys, Home, and End are native range input keyboard behavior and are preserved.
  • When projected inside kui-field, kuiSlider inherits the field id, aria-describedby, and aria-invalid.
  • Use invalid only when the slider is outside field error wiring.
  • The default tooltip shows the current numeric value on hover, and also on keyboard focus and while adjusting with the keyboard, so arrow-key users see what they set. It is hoverable and Escape dismisses it (WCAG 1.4.13). A non-empty kuiTooltip on the same host overrides it with static text.
  • Disabled sliders get native disabled semantics, and the track, fill and thumb stay visible under forced-colors: active.
  • The directive class is KuiSlider; the Directive suffix is gone.
  • Size and colour defaults moved to provideKuiDefaults({{ '{' }} slider: {{ '{' }} size, color {{ '}' }} {{ '}' }}); the inputs are now undefined until set.
  • The value tooltip also shows on keyboard focus and while adjusting with the keyboard, and Escape dismisses it.
  • Every colour part has a token, and the thumb and track have size tokens (--kui-slider-thumb-size, --kui-slider-track-size) and shadow tokens.
  • A required kui-field sets aria-required, and the slider is covered by forced-colors.
