A link acting as a heading goes inside an h1 to h6, not the other way round, so heading semantics never depend on the text being a link. Font size, weight and line height follow the selected --kui-type-<variant>-* tokens.

  • An external link gets rel="noopener noreferrer" merged with any rel you set.
  • The library's own external-link glyph fills the iconEnd slot unless you pass an explicit iconEnd. It is a structural icon: synchronous icon data drawn as inline SVG. Replace it with defaults.link.externalIcon or the externalLink role.
  • A visually hidden suffix, the link.opensInNewTab message ((opens in a new tab) by default), is appended to the accessible name.

kuiLink composes kuiText for its role class but ignores defaults.typography, because a link owns its text colour (defaults.link.tone).

  • The visible text is the accessible name; icons are decorative and never the only meaning.
  • :focus-visible shows an explicit ring (--kui-link-focus-ring).
  • Colour is never the only signal: default, hover, focus and active differ by underline thickness and, for focus, the ring. Avoid underline="none" inside running text.
  • Disabled links are excluded from the tab order.
  • Enter activates a link or button; Space activates only a button host.
  • There is no visited tone or state; add a --kui-link-color-visited token yourself if a product needs it.
  • There is no distinct active appearance from hover; both use the thicker underline.
