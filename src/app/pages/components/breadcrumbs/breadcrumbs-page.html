• A span[kuiBreadcrumbItem] without current is plain text and is not focusable.
  • current is meaningful on a span only and sets aria-current="page".
  • An optional leading icon goes on the first crumb only, inside a span.kui-breadcrumb-icon.
  • Use <nav aria-label="Breadcrumb"> around the trail.
  • Keep navigable ancestors as native links.
  • Render the current page as non-focusable text with current.
  • Collapse long mobile trails with first/last crumbs or a separate menu pattern.
  • Breadcrumb links intentionally do not compose kuiLink: breadcrumbs own their navigation spacing, size scale, tokens and current-page treatment. Keep navigable crumbs as native anchors with kuiBreadcrumbItem.
  • The ellipsis button needs an accessible name (for example aria-label) and opens a menu that lists the hidden levels.
  • The classes are KuiBreadcrumbs, KuiBreadcrumbItem and KuiBreadcrumbSeparator (they had a Directive or Component suffix). ng update @kikita-labs/ui renames the imports.
  • The default size comes from defaults.breadcrumbs.size and the separator icon from defaults.breadcrumbs.separatorIcon (it takes precedence over defaults.icons.separator).
  • The ellipsis, separator and truncation sizes are geometry tokens, and the focus ring is the shared 2px outline.
