Every column centers on its selected cell when the panel opens and after each selection. Selecting a cell does not close the panel, so hours, minutes and seconds can all be picked; close with Enter, Escape, an outside click or the panel's Done button. Now sets the current time without closing.

  • Typing digits inserts the locale separator (2214 becomes 22:14, or 22.14 in da-DK); characters that could never be part of a value are stripped, and the input length is capped per format.
  • Each group clamps to its valid maximum once both digits are typed (99:99 becomes 23:59) and snaps to the nearest step.
  • For 12h the AM/PM suffix is optional: a fully typed hh:mm commits at once and keeps the previous period.
  • aria-invalid is set for an incomplete group such as 12:3 and for a value in an excluded range or on a disabled slot, without discarding the last valid value.
  • The caret always lands at the end of the field after typing, and digits are Latin in every locale.
  • The input has role="combobox", aria-haspopup="dialog", aria-expanded and aria-controls for the popover panel.
  • Each column is a focusable role="listbox" named Hours, Minutes or Seconds with role="option" cells and aria-selected; the selected cell is also distinct by fill and weight, not colour alone, and the focus ring is styled explicitly.
  • AM/PM is a kui-segmented radio group, keyboard accessible as part of the kit.
  • ArrowDown on the closed input opens the popover and focuses the first column; Enter toggles it; Escape closes it and keeps focus in the field; Tab closes it and moves on.
  • In a column ArrowUp and ArrowDown move cyclically and apply at once, Home and End jump to the first and last value, and Enter closes the popover keeping the selection.
  • Disabled uses the native attribute on the input and the chevron. Pair an invalid value with the error of kui-field for an announced alert.
  • Range picking (from and to) is not implemented.
  • Now only clamps into minTime and maxTime, not around the disabled function results, so it can land on a disabled slot and is then marked invalid.
  • aria-controls does not point at the real dropdown panel id before the first open, the same gap as the date picker.
  • The leading clock icon is a structural glyph with no override slot yet; the clear and chevron icons have one.
