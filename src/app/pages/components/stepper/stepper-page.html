• kui-stepper renders role="list" and each kui-step renders role="listitem"; pass aria-label on the host, for example Progress.
  • The current step has aria-current="step".
  • Completed steps (and upcoming steps when linear is false) render their circle as a native button named by the stepper.backToStep and stepper.goToStep messages; disabled steps are plain spans out of the tab order.
  • Connector lines are decorative (aria-hidden="true").
  • Use descriptive labels and optional descriptions for each step.
  • Linear mode prevents activating upcoming steps.
  • Error steps disable later steps until the flow recovers.
  • Use vertical orientation when labels need more horizontal space.
  • The classes are KuiStepper and KuiStep; the Component suffix is gone.
  • Size, orientation, linear and compact defaults moved to provideKuiDefaults({{ '{' }} stepper: {{ '{' }} ... {{ '}' }} {{ '}' }}); the inputs are now undefined until set.
  • The back and go-to button names come from the stepper.backToStep and stepper.goToStep messages.
  • Every colour part has a token, plus font-size, gap and dot-size geometry tokens.
