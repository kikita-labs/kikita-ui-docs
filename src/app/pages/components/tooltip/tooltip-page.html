• With triggerType="auto", it shows on hover and keyboard focus for mouse input.
  • With triggerType="auto", it toggles on tap for touch input.
  • Use hover to disable touch taps, click to toggle on every device, or none to disable it.
  • Whitespace-only tooltip text is ignored.
  • Tooltip content renders through CDK Overlay and layers above floating panels.
  • Keep a visible label or accessible name on the trigger itself.
  • Use tooltip text for short hints, not form errors or instructions required to finish a task.
  • aria-describedby is present only while the floating tooltip exists.
  • The tooltip is hoverable, dismissible with Escape and persistent while hovered or focused (WCAG 1.4.13). A tap-open tooltip closes on a second tap, an outside tap, focus moving outside or Escape.
  • Use a native interactive element, normally a button, as the trigger.
  • Respect reduced-motion users; the package disables tooltip animation when requested.
  • The directive class is KuiTooltip; the Directive suffix is gone.
  • kuiProvideTooltipOptions and KUI_TOOLTIP_OPTIONS are replaced by provideKuiDefaults({{ '{' }} tooltip: {{ '{' }} ... {{ '}' }} {{ '}' }}); a nested level merges with its parent per property.
  • Defaults now cover placement and offset besides triggerType, and the tooltip has a new offset input.
  • The default trigger opens the tooltip on touch taps; set triggerType="hover" to keep the previous touch-disabled behaviour or none to disable it on all devices.
  • The tooltip is hoverable and dismissible with Escape (WCAG 1.4.13), and its exit animation uses --kui-duration-quick and --kui-ease-exit.
