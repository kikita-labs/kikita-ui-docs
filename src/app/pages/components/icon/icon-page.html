• A glyph is {{ '{' }} node, viewBox? {{ '}' }}, where node lists drawing elements in paint order in the icon-node layout of Lucide; only path, line, polyline, polygon, circle, ellipse and rect are drawn, and an unknown element invalidates the glyph.
  • strokeWidth sets --kui-icon-stroke-width in glyph-grid units (24 by 24 for Lucide) and absoluteStrokeWidth keeps the stroke the same number of pixels at any size (--kui-icon-vector-effect: non-scaling-stroke). Both are plain CSS custom properties, so they also work on :root or a subtree. Filled shapes and markup with an inline stroke-width style are not affected.
  • The default Lucide set is read at a pinned lucide-static version (KUI_LUCIDE_STATIC_VERSION, 1.51.0), so a library release always draws the same icons. The fetched file is converted to glyph data with the allowlist instead of being inserted as HTML: a replaced or compromised file cannot inject script or load another resource, and a file with anything else (script, use, text) is rejected and the icon stays empty. Names that are not Lucide kebab-case names resolve to nothing without a request.
  • Allow connect-src https://cdn.jsdelivr.net in a Content Security Policy, host the files yourself with createKuiLucideResolver({{ '{' }} baseUrl {{ '}' }}), or set provideKikitaUi({{ '{' }} icons: false {{ '}' }}) to make no request at all. Names resolved through the default set need a request, so they render when it settles; a name found in a static registry renders on the first pass.
  • Register SVG strings from static application code only and pass only trusted static SVG to [source]; return glyph data from a custom resolver so a response cannot carry markup, and never resolve a name to a URL built from user input.
  • Use src for normal image URLs when you do not need inline SVG styling.
  • Omit label for decorative icons so they are hidden from assistive technology.
  • Provide label when the icon itself communicates status, action, or identity.
  • Prefer visible text next to icons for actions; icon-only buttons need an accessible name.
  • Keep icon sizing proportional to surrounding text or control height.
  • The class is KuiIcon (it was KuiIconComponent); ng update @kikita-labs/ui renames the import.
  • The default Lucide set moved from the floating lucide-static@1 to a pinned version, is converted to glyph data and may need connect-src in your CSP. KuiIconSource stays the markup string type; registries and resolvers may also return KuiIconGlyph data.
  • provideKuiIcons() returns environment providers: put it in the application config, a route or an environment injector. A static registry answers on the first pass without a promise, and names are matched against the registry's own keys only, so name="constructor" no longer returns a function.
  • New inputs strokeWidth and absoluteStrokeWidth, and a kui.components layer stylesheet: kui-icon needs kikita-ui.css like every other component.
