• Provide an accessible name through aria-label or a kui-field label.
  • Generated buttons are named by the numberInput.decrease and numberInput.increase messages (Decrease value and Increase value by default), plus native disabled and aria-disabled="true" when stepping is not available.
  • Native keyboard behavior on the input remains available: ArrowUp, ArrowDown, Home, and End.
  • Press and hold a generated button for repeated stepping after a 400 ms delay; Enter or Space on a focused button steps once.
  • A disabled or readonly native input sets data-kui-disabled or data-kui-readonly on the container and disables both buttons.
  • Place the input inside kui-field to inherit label, hint, error, and id wiring instead of wiring ARIA by hand.
  • The directive class is KuiNumberInput; the Directive suffix is gone.
  • variant values are split (side controls, default) and stacked; the old b and a names are gone.
  • Size and variant defaults moved to provideKuiDefaults({{ '{' }} numberInput: {{ '{' }} size, variant {{ '}' }} {{ '}' }}); the inputs are now undefined until set.
  • The decrease and increase button names come from the numberInput.decrease and numberInput.increase messages.
  • Button hover, active, disabled and readonly states have colour tokens, and the field padding has --kui-number-input-field-padding-inline.
