• The host element gets role="status" and aria-live="polite" automatically; no extra ARIA wiring is required.
  • label sets the accessible name via aria-label and defaults to the common.loading message (Loading), so it follows the active locale. Provide a specific label (for example Saving) whenever the loading context is not obvious from surrounding text.
  • Since 0.3.0, the loader keeps flex-shrink: 0 so it no longer collapses into an oval when its flex container shrinks it, such as inside a wrapped multi-line button label.
  • When composed inside a kuiButton with native disabled, the button itself communicates the busy state to assistive technology; keep disabled set for the duration of the loading state.
  • The directive class is KuiLoader; the Directive suffix is gone.
  • The default size moved to provideKuiDefaults({{ '{' }} loader: {{ '{' }} size {{ '}' }} {{ '}' }}).
  • The default label now comes from the common.loading message, so it follows provideKuiLocale and provideKuiMessages; an unset label is undefined.
  • --kui-loader-duration-reduced sets the spin duration under reduced motion.
  • A loading Button keeps full opacity, and a kuiLoader placed inside a Button takes the button text colour.
