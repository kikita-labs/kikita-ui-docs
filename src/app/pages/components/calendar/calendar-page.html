• Use kui-calendar-range (KuiCalendarRange) when the value is a KuiDateRange; kui-calendar selects a single date.
  • minDate, maxDate and disabledDates block days; disabledDates takes dates or a predicate. minDate and maxDate are models, so a paired date picker can wire them for you.
  • Use flat inside kui-dropdown so panel chrome is not doubled, and size="sm" for tight sidebars. The width is --kui-calendar-width (296px).
  • viewDate (a first-of-month date, two-way) moves the displayed month from the outside. showPrevNav and showNextNav hide one navigation control for two linked calendars a month apart.
  • Placed next to input[kuiDatePicker] in the same kui-field, the directive wires value, viewDate and the bounds automatically; see Date Picker.
  • The locale starts from the app-wide KUI_LOCALE (the browser language, or the request's Accept-Language on the server), falls back to en-US, and is overridden per instance by the locale input.
  • Day buttons are named with the full localized date, for example Saturday, October 3, 2026, and the weekend follows the locale (a Friday and Saturday weekend in he-IL).
  • messages overrides the calendar texts for one instance; it wins over scoped and root messages. Names use the Gregorian calendar and Latin digits.
  • The day grid is a complete ARIA grid: role="grid" holds the weekday header row (columnheader cells carry the full weekday name as abbr) and six week rows of seven gridcells, each wrapping one day button.
  • aria-selected sits on the selected gridcell, not on the button; today exposes aria-current="date" and disabled dates aria-disabled.
  • One day is in the tab order at a time: the selected date when it is in the displayed month, otherwise today when visible, otherwise the first day of the month.
  • Keyboard: ArrowLeft and ArrowRight move a day, ArrowUp and ArrowDown a week, Home and End the start and end of the week, PageUp and PageDown a month (with Shift a year), and Enter or Space selects. Focus follows into the next month.
  • Month and year changes are announced through an aria-live="polite" region.
  • Provide nearby text or a surrounding field label when the calendar appears in a larger form.
  • Assistive-technology review is still pending for the newest date primitives.
  • The class is KuiCalendar (it was KuiCalendarComponent); ng update @kikita-labs/ui renames the import.
  • kui-calendar is single-date only: the mode input and the Date | KuiDateRange | null value union are gone. Range selection moved to kui-calendar-range.
  • kuiProvideLocale is provideKuiLocale and returns an array of providers; the locale is checked against the runtime's Intl and falls back to en-US.
  • The grid markup is a full ARIA grid. CSS that targets .kui-calendar-grid > .kui-calendar-day must target .kui-calendar-day or the new week and cell wrappers; tests that look up a day button by its bare number must use the full date as its name.
