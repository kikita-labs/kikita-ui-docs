length defaults to 6. size uses the xs to lg scale of Input. autoFocus focuses the first cell after render.

  • Inside kui-field the first cell adopts the field control id, so the label targets it and a click on the label focuses it. The hint and error reach the group through aria-describedby.
  • kui-otp-input implements FormValueControl<string>: put [formField] on it, not on kui-field. A required validator message and the invalid cell styling stay hidden until the field is touched.
  • focus(options?) moves focus to the first cell that can take focus, so field().focusBoundControl() works.
  • The group is role="group" with the ariaLabel or the otpInput.label message; each cell has its own Digit N of M name from the otpInput.digit message.
  • Typing a valid character fills the cell and moves to the next empty one. Backspace on an empty cell clears and refocuses the previous cell. ArrowLeft and ArrowRight move without changing values, and Home and End jump to the first and last cell. Tab leaves the whole group.
  • Ctrl or Cmd + V distributes a pasted code from the first cell, whichever cell had focus.
  • The first cell carries autocomplete="one-time-code" for SMS autofill on iOS and Android.
  • disabled and loading use the native attribute, so the cells leave the tab order. readonly also blocks paste and the cross-cell Backspace clear.
  • Clearing a cell while later cells stay filled collapses those positions in the joined value, as in other OTP inputs.
  • There is no built-in success or error status icon after verification.
  • A formal assistive-technology review has not been run.
