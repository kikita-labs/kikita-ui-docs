To recolour a solid inside a subtree, override the fill together with -on-fill, -fill-away and -indicator, or set a different seed through the provider. --kui-color-on-fill and --kui-color-primary-focus-ring are deprecated and removed in 3.0.

The generated stylesheet does not define the component hooks, so a global token set on a subtree is never shadowed by a copy of its value on the root. Loops keep their own tokens: --kui-loader-duration, --kui-loader-duration-reduced, --kui-skeleton-duration and --kui-field-spinner-duration.

Card, Segmented, Tabs and Table no longer read the Button hooks --kui-btn-focus-ring-w and --kui-btn-focus-ring-off; set --kui-focus-ring-width and --kui-focus-ring-offset to change every ring at once.
