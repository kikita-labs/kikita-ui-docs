• Every focusable part draws a solid 2px outline in --kui-color-focus, which stays visible in forced-colors mode. A ring drawn only with box-shadow is gone, and --kui-input-focus-ring defaults to none.
  • kui-field sets aria-required from its merged required state on every control whose role supports it. A single radio and a slider are the documented exceptions.
  • Automatic focus (kuiAutoFocus, OTP autoFocus) is opt-in and limited to places where focus on arrival is expected.
  • Safari on macOS does not focus a button when it is clicked with the mouse, so a modal surface opened by mouse has no trigger to return focus to on close. Focus returns to the trigger when the surface was opened with the keyboard; native dialog, Angular CDK and Angular Material behave the same way, and Kikita UI does not work around it. Test focus return in Safari by opening the surface with the keyboard.
  • Right-to-left layouts are not supported in 2.0.
  • Respect prefers-reduced-motion for nonessential animation. Essential motion has a non-motion cue, and focus, selected, invalid, disabled and loading states stay distinguishable without colour alone.
  • Control borders follow WCAG 1.4.11: a boundary that alone identifies a control (an input, a checkbox) reaches 3:1 in the default strict contrast profile. The opt-in soft profile drops control borders below 3:1 and is documented as such, and prefers-contrast: more selects strict while no data-kui-contrast attribute is set.
  • The library ships forced-colors rules in forced-colors.css using system colours, covering checked and indeterminate controls, Slider, Progress, selected cells, Tabs, Segmented, pressed Chip, Stepper and the charts. Browser emulation of forced colors only toggles the media query, so a real Windows pass is still needed.
  • Icons are drawn as inline SVG with currentColor, so they take the system text colour. An icon drawn with a CSS mask-image and background: currentColor disappears in Chromium in forced-colors mode.
  • Semi-transparent overlays and shadows are never the only way to communicate depth or modality.
